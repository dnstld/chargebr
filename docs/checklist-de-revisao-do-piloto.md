# Checklist de revisão do piloto

## Objetivo

Permitir que uma pessoa revisora avalie cada caso do piloto de forma independente, reproduzível e comparável, usando somente os registros preparados e as fontes neles referenciadas.

O checklist avalia a qualidade da representação, não se a pessoa revisora concorda com a importância editorial do tema.

## Respostas permitidas

- **`PASS`:** o requisito foi atendido e a evidência está indicada.
- **`FAIL`:** o requisito não foi atendido, não pode ser comprovado ou depende de informação não registrada.
- **`N/A`:** o requisito não se aplica ao caso e a justificativa está registrada.

Ausência de evidência não é `N/A`. Não existe pontuação média: um item com `FAIL` não pode ser compensado por outros itens aprovados.

## Lacunas encontradas

Registrar uma linha por lacuna:

| ID | Categoria | Severidade | Descrição | Evidência | Próxima decisão |
| --- | --- | --- | --- | --- | --- |
|  | `registro`, `documentação`, `restrição`, `modelo`, `metodologia` ou `fonte` | `bloqueante` ou `não bloqueante` |  |  |  |

Uma lacuna de registro pode ser corrigida sem alterar a fundação. Lacunas de restrição, modelo ou metodologia exigem decisão revisada antes de modificar o schema ou o método.

## Resultado da revisão

Selecionar exatamente um resultado:

- **`ACCEPTED`:** todos os itens aplicáveis passaram e não existem lacunas bloqueantes.
- **`CORRECTION_REQUIRED`:** a fundação parece suficiente, mas os registros precisam ser corrigidos e revisados novamente.
- **`FOUNDATION_REVIEW_REQUIRED`:** existe lacuna bloqueante de restrição, modelo ou metodologia.
- **`INCONCLUSIVE`:** uma limitação de fonte impede concluir a revisão sem justificar uma alteração da fundação.

Registrar a conclusão:

| Campo | Valor |
| --- | --- |
| Resultado |  |
| Itens com `FAIL` |  |
| Lacunas bloqueantes |  |
| Síntese reconstruída pela pessoa revisora |  |
| Próxima ação |  |

## Regra para avançar

Um caso só pode ser considerado concluído com resultado `ACCEPTED`. Qualquer outro resultado impede o início do caso seguinte até que a correção, a decisão sobre a fundação ou a limitação de fonte esteja documentada.

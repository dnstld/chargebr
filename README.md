# ChargeBR

Plataforma de inteligência sobre mobilidade elétrica no Brasil.

## Estado do projeto

O projeto está em sua fase inicial. A documentação e a estrutura de dados serão construídas e revisadas em pequenas etapas.

## Estrutura inicial

- `docs/`: documentação do projeto.
- `supabase/migrations/`: futuras migrações do banco de dados.
- `supabase/seed.sql`: futuros dados iniciais para desenvolvimento.
